Словесная запись алгоритма
1. Ввести общее количество секунд (целое неотрицательное число).
2. Проверить корректность ввода: если введено не число или число меньше 0, вывести сообщение об ошибке и завершить программу.
3. Вычислить количество часов: разделить общее количество секунд на 3600 (целочисленное деление).
4. Вычислить остаток секунд после выделения часов: взять остаток от деления общего количества секунд на 3600.
5. Вычислить количество минут: разделить полученный остаток на 60 (целочисленное деление).
6. Вычислить количество оставшихся секунд: взять остаток от деления предыдущего остатка на 60.
7. Вывести результат в формате: часы, минуты, секунды.

Псевдокод

АЛГОРИТМ Перевод Секунд
ВХОД: total seconds (целое число)
ВЫХОД: hours, minutes, seconds

НАЧАЛО
    ВВОД total_seconds
    ЕСЛИ total_seconds < 0 ТОГДА
        ВЫВОД "Ошибка: введено некорректное число"
        ЗАВЕРШИТЬ
    КОНЕЦ ЕСЛИ

    hours = total_seconds DIV 3600
    rem = total_seconds MOD 3600
    minutes = rem DIV 60
    seconds = rem MOD 60

    ВЫВОД hours, " часов ", minutes, " минут ", seconds, " секунд"
КОНЕЦ

Проверка на контрольных вводах
1. Ввод 3725 -> 1 часов 2 минут 5 секунд
2. Ввод 59 -> 0 часов 0 минут 59 секунд
3. Ввод 86399 -> 23 часов 59 минут 59 секунд
4. Ввод 0 -> 0 часов 0 минут 0 секунд
