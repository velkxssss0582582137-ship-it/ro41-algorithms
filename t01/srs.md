Примеры свойств алгоритмов из жизни колледжа

1. Дискретность
Исходная формулировка с нарушением: Напиши курсовую работу по программированию.
Какое свойство нарушено и почему: Нарушено свойство дискретности. Процесс выполнения не разбит на отдельные элементарные шаги, выполнение которых можно проконтролировать по отдельности.
Исправленная формулировка: Сначала выбери тему курсовой работы у преподавателя, затем найди и изучи литературу, после этого напиши теоретическую и практическую части, а в конце оформи работу по требованиям и сдать на проверку.

2. Понятность
Исходная формулировка с нарушением: Сделай рефакторинг бэкенда через консоль Linux с правами суперпользователя.
Какое свойство нарушено и почему: Нарушено свойство понятности. Команда содержит термины и действия, которые исполнитель не знает и не умеет выполнять, так как система команд для него не определена.
Исправленная формулировка: Открой текстовый редактор на компьютере, создай новый файл с именем Program.cs и вставь в него готовый шаблон кода, показанный на доске.

3. Определённость
Исходная формулировка с нарушением: Добавь в чай немного сахара и завари кипятком.
Какое свойство нарушено и почему: Нарушено свойство определённости. Использование субъективных мер делает команду неоднозначной, у разных исполнителей получится разный результат.
Исправленная формулировка: Насыпь в чашку ровно две чайные ложки сахара, залей 200 миллилитров кипятка и перемешивай ложкой в течение тридцати секунд.

4. Результативность
Исходная формулировка с нарушением: Переписывай конспект по истории бесконечное количество раз, пока полностью не выучишь все даты наизусть.
Какое свойство нарушено и почему: Нарушено свойство результативности. Алгоритм не гарантирует завершение работы за конечное число шагов.
Исправленная формулировка: Перепиши конспект по истории ровно три раза и сдай тетрадь преподавателю на проверку.

5. Массовость
Исходная формулировка с нарушением: Рассчитай итоговую оценку по информатике только для студента Иванова Ивана из группы ИС-21, который сдал работу ровно 15 сентября в 10:15.
Какое свойство нарушено и почему: Нарушено свойство массовости. Инструкция жестко привязана к одному конкретному человеку и уникальной ситуации, её нельзя применить для других студентов.
Исправленная формулировка: Введи оценки за лабораторные работы любого выбранного студента, сложи полученные баллы и раздели их на общее количество работ для получения среднего значения.
