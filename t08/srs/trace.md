Задание 1



Ручная трассировка метода s.Trim() и Split(';').

Исходная строка: s = " Ахметов Ерлан;85 ".

После выполнения метода s.Trim() получается строка без пробелов по краям: "Ахметов Ерлан;85".

После применения Split(';') строка разделяется на два элемента:

Первый элемент: "Ахметов Ерлан", его длина равна 13 символам.

Второй элемент: "85", его длина равна 2 символам.



Задание 2



Трассировка int.TryParse для строки line = "Иванов Пётр;70;85;x".

После разделения через Split(';') получается четыре части:

Часть первая: "Иванов Пётр", результат TryParse равен false, значение out равно 0, так как текст нельзя преобразовать в число.

Часть вторая: "70", результат TryParse равен true, значение out равно 70.

Часть третья: "85", результат TryParse равен true, значение out равно 85.

Часть четвертая: "x", результат TryParse равен false, значение out равно 0, так как символ не является числом.

Метод проверки вернет false, потому что не все элементы массива смогли успешно пройти преобразование через int.TryParse.



Задание 3



Сравнение создания объектов для string и StringBuilder.

При выполнении цикла с s += i создается 5 объектов string (один пустой исходный объект и по одному новому объекту на каждой из четырех итераций, так как строки неизменяемы).

При использовании StringBuilder создается всего 1 объект StringBuilder, который изменяет свой внутренний буфер без создания новых объектов на каждом шаге.



По шагам от 0 до 3:

На этапе инициализации для string создается 1 объект пустой строки, для StringBuilder создается 1 объект.

На шаге i равном 0 для string создается новый объект "0" (всего 2), для StringBuilder используется тот же 1 объект.

На шаге i равном 1 для string создается новый объект "01" (всего 3), для StringBuilder используется тот же 1 объект.

На шаге i равном 2 для string создается новый объект "012" (всего 4), для StringBuilder используется тот же 1 объект.

На шаге i равном 3 для string создается новый объект "0123" (всего 5), для StringBuilder используется тот же 1 объект.



Задание 4



Строки в C# являются неизменяемыми. Такие методы, как ToUpper(), не меняют существующий объект в памяти, а создают и возвращают новую измененную строку. Если результат работы метода не присвоить переменной обратно, то исходная строка остается прежней, а переменная продолжает указывать на нее.
