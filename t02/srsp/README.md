АЛГОРИТМ Подсчет Цифр И Суммы
ВХОД: n (целое число)
ВЫХОД: count (количество цифр), sum (сумма цифр)

НАЧАЛО
    ВВОД n
    ЕСЛИ n < 0 ТОГДА
        ВЫВОД "Ошибка: введено некорректное число"
        ЗАВЕРШИТЬ
    КОНЕЦ ЕСЛИ

    count = 0
    sum = 0
    temp = n

    ЦИКЛ
        digit = temp MOD 10
        sum = sum + digit
        count = count + 1
        temp = temp DIV 10
    ПОКА temp > 0

    ВЫВОД "Количество цифр: ", count
    ВЫВОД "Сумма цифр: ", sum
КОНЕЦ
