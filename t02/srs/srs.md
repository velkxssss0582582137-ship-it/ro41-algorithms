Вычисление факториала (для n = 5)

Инициализация:
- n = 5
- f = 1

Итерации цикла (для i от 1 до 5):
- Итерация i = 1: f = 1 * 1 = 1
- Итерация i = 2: f = 1 * 2 = 2
- Итерация i = 3: f = 2 * 3 = 6
- Итерация i = 4: f = 6 * 4 = 24
- Итерация i = 5: f = 24 * 5 = 120

Результат выполнения алгоритма А:
Вывод f = 120

Умножение числа на 2 до достижения 100

Инициализация:
- x = 3
- k = 0

Итерации цикла (пока x < 100):
- Итерация 1: x = 3 < 100 (Истина) -> x = 3 * 2 = 6, k = 0 + 1 = 1
- Итерация 2: x = 6 < 100 (Истина) -> x = 6 * 2 = 12, k = 1 + 1 = 2
- Итерация 3: x = 12 < 100 (Истина) -> x = 12 * 2 = 24, k = 2 + 1 = 3
- Итерация 4: x = 24 < 100 (Истина) -> x = 24 * 2 = 48, k = 3 + 1 = 4
- Итерация 5: x = 48 < 100 (Истина) -> x = 48 * 2 = 96, k = 4 + 1 = 5
- Итерация 6: x = 96 < 100 (Истина) -> x = 96 * 2 = 192, k = 5 + 1 = 6
(После итерации 6 условие x < 100 становится ложным: 192 < 100 — Ложь, цикл завершается).

Результат выполнения алгоритма Б:
Вывод x = 192, k = 6
