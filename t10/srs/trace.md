Задание 1

Трассировка сортировки выбором для массива a = {5, 2, 9, 1, 7}:

Проход i = 0: индекс минимума равен 3 (значение 1), массив после обмена: {1, 2, 9, 5, 7}, число сравнений на проходе: 4.

Проход i = 1: индекс минимума равен 1 (значение 2), массив после обмена: {1, 2, 9, 5, 7}, число сравнений на проходе: 3.

Проход i = 2: индекс минимума равен 3 (значение 5), массив после обмена: {1, 2, 5, 9, 7}, число сравнений на проходе: 2.

Проход i = 3: индекс минимума равен 4 (значение 7), массив после обмена: {1, 2, 5, 7, 9}, число сравнений на проходе: 1.
Общее число сравнений: 10.

Задание 2

Трассировка сортировки вставками для массива a = {4, 3, 2, 1}:

i = 2, key = 2, число сдвигов: 2, массив после вставки: {2, 3, 4, 1}.

Всего сдвигов: 6.
На уже отсортированном массиве из 4 элементов алгоритм выполнит 3 сравнения.

Задание 3

Трассировка бинарного поиска для x = 7 в массиве {1, 3, 5, 7, 9, 11, 13}:

Шаг 1: lo = 0, hi = 6, mid = 3, a[mid] = 7, решение: найдено, индекс 3.

Поиск для x = 6:

Шаг 1: lo = 0, hi = 6, mid = 3, a[mid] = 7, решение: 7 > 6, hi становится равным 2.

Шаг 2: lo = 0, hi = 2, mid = 1, a[mid] = 3, решение: 3 < 6, lo становится равным 2.

Шаг 3: lo = 2, hi = 2, mid = 2, a[mid] = 5, решение: 5 < 6, lo становится равным 3.
Поиск закончится неудачей и вернет -1, так как lo превысит hi.
Значение, которое вернет LowerBound(6): 3 (индекс первого элемента, который больше или равен 6, то есть числа 7).
